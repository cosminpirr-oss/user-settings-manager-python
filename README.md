# Configuration Manager (Python)

Acest proiect demonstrează abilitățile mele de programare în **Python**, axându-se pe manipularea structurilor de date și logica de tip CRUD.

## ⚙️ Funcționalități:
- Adăugarea de noi setări într-un dicționar.
- Actualizarea setărilor existente.
- Ștergerea și vizualizarea configurațiilor.
- Normalizarea datelor (convertește automat input-ul în litere mici).

## 🐍 Tehnologii folosite:
- Python 3
- Dicționare și Tupluri
- Logica condițională și bucle (loops)
